BPMT Lite API Docs

v1.4.0 动态表结构 API。文档公开访问，业务接口需要 HMAC 请求头。

入口

OpenAPI JSON：/api/openapi.json

业务前缀：/api/v1

签名

请求头：X-BPMT-App-Key、X-BPMT-Timestamp、X-BPMT-Nonce、X-BPMT-Signature。

canonical = METHOD + "\n"
  + PATH + "\n"
  + NORMALIZED_QUERY + "\n"
  + TIMESTAMP + "\n"
  + NONCE + "\n"
  + SHA256_HEX(BODY)

signature = HEX(HMAC_SHA256(APP_SECRET, canonical))

PATH 使用公开请求 URI，例如 /api/v1/dynamic-tables。NORMALIZED_QUERY 按解码后的参数名和值排序后再编码。

接口

动态表列表支持 sort/order 排序；默认 sort=createDate&order=desc，便于优先看到新创建的表。允许的排序字段以 OpenAPI 为准。
