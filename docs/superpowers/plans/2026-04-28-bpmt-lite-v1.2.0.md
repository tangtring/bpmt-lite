### Task 3: Add Dual Database Initialization

**Files:**
- Create: `scripts/init-db.sh`
- Create: `database/bpmt.sql.gz` from the current curated `bpmt` database dump
- Create or rename locally: `database/bpmt-min.sql`
- Commit: `database/bpmt-min.sql.gz`
- Modify: `docker-compose.yml`
- Create: `docs/v1.2.0/database-init.md`

**Current note:** the old local `db/init/kyq.sql` was removed from this project folder at the user's request. The curated full database is exported as local ignored `database/bpmt.sql` and committed as compressed `database/bpmt.sql.gz`. The minimal database follows the same rule: raw `database/bpmt-min.sql` is local ignored output, while `database/bpmt-min.sql.gz` is committed.

- [x] **Step 1: Define script behavior**

`scripts/init-db.sh` must support:

```bash
scripts/init-db.sh
scripts/init-db.sh min
```

Default mode prepares the full database SQL for `bpmt`. `min` mode prepares the minimal SQL for `bpmt_min`.

- [x] **Step 2: Implement script skeleton**

Create executable `scripts/init-db.sh`:

```sh
#!/bin/sh
set -eu

MODE="${1:-full}"
BASE_URL="${BPMT_SQL_BASE_URL:-https://raw.githubusercontent.com/wodenwang/bpmt-lite/v1.2.0/database}"
mkdir -p db/init

case "$MODE" in
  full)
    target="db/init/bpmt.sql"
    url="$BASE_URL/bpmt.sql.gz"
    ;;
  min)
    target="db/init/bpmt-min.sql"
    url="$BASE_URL/bpmt-min.sql.gz"
    ;;
  *)
    echo "Usage: scripts/init-db.sh [min]" >&2
    exit 2
    ;;
esac

curl -fsSL "$url" | gzip -dc > "$target"
echo "Initialized $target"
```

- [x] **Step 3: Ensure SQL databases do not conflict**

Each public SQL file must start with its own database selection:

```sql
CREATE DATABASE IF NOT EXISTS bpmt DEFAULT CHARACTER SET utf8 COLLATE utf8_general_ci;
USE bpmt;
```

and:

```sql
CREATE DATABASE IF NOT EXISTS bpmt_min DEFAULT CHARACTER SET utf8 COLLATE utf8_general_ci;
USE bpmt_min;
```

- [x] **Step 4: Update compose defaults**

Set default `DB_NAME` to `bpmt` in `docker-compose.yml` for the Web container and MariaDB initialization environment. Document `DB_NAME=bpmt_min` as the minimal database switch.

- [x] **Step 5: Validate coexistence**

Run:

```bash
docker compose down
rm -rf db/data
scripts/init-db.sh
scripts/init-db.sh min
docker compose up -d
docker compose exec mariadb mariadb -uroot -p123456 -e "SHOW DATABASES LIKE 'bpmt%';"
```

Expected: both `bpmt` and `bpmt_min` are present.

Verified in a temporary MariaDB 10.11 container: `scripts/init-db.sh` plus `scripts/init-db.sh min` produced importable SQL, and both `bpmt` and `bpmt_min` existed after import. Table counts were `bpmt=377` and `bpmt_min=173`; `bpmt` excludes the broken `v_demo_qj` view because its base demo tables are absent.
