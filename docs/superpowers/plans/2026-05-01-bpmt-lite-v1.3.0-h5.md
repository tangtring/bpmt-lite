# bpmt-lite v1.3.0 H5 Repair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore mobile H5 login, homepage, menu, list/detail browsing, and two high-frequency operation smoke paths for `bpmt-lite` v1.3.0.

**Architecture:** Keep Java 8, Maven 3, Tomcat 7, JSP/FTL, and the existing Action framework unchanged. First repair the H5 routing and resource-loading breakages, then add a small local `bpmt-h5` CSS/JS layer that works without external CDN resources and remains compatible with legacy AmazeUI templates.

**Tech Stack:** Java 8, Maven 3, Tomcat 7, JSP/JSTL, legacy Action framework, jQuery 1.x, Docker Compose, MariaDB.

- [ ] **Step 5: Create first-pass H5 JS**

Create `platform/src/main/webapp/h5/assets/bpmt-h5.js`:

```javascript
(function(window, document) {
	if (!window.wx) {
		window.wx = {};
	}
	if (typeof window.wx.closeWindow !== 'function') {
		window.wx.closeWindow = function() {
			if (window.history.length > 1) {
				window.history.back();
			}
		};
	}

	function removeById(id) {
		var node = document.getElementById(id);
		if (node && node.parentNode) {
			node.parentNode.removeChild(node);
		}
	}

	window.BpmtH5 = {
		showLoading: function(message) {
			removeById('bpmt_h5_loading');
			var loading = document.createElement('div');
			loading.id = 'bpmt_h5_loading';
			loading.className = 'bpmt-h5-loading';
			loading.innerHTML = '<div>' + (message || '数据加载中') + '</div>';
			document.body.appendChild(loading);
		},
		hideLoading: function() {
			removeById('bpmt_h5_loading');
		},
		toast: function(message) {
			removeById('bpmt_h5_toast');
			var toast = document.createElement('div');
			toast.id = 'bpmt_h5_toast';
			toast.className = 'bpmt-h5-toast';
			toast.innerHTML = message || '';
			document.body.appendChild(toast);
			window.setTimeout(function() {
				removeById('bpmt_h5_toast');
			}, 2400);
		}
	};
})(window, document);
```
