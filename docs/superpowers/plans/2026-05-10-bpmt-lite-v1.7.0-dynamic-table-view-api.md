# bpmt-lite v1.7.0 Dynamic Table View API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `v1.7.0` with a complete external API for creating, validating, exporting, updating, patching, and deleting `dyn` dynamic table view configuration.

**Architecture:** Add a new `dynamic_table_views` module inside the existing `api` WAR and keep all public endpoints under `/api/v1/dynamic-table-views`. The module owns an agent-facing snapshot model, maps that model to `VW_URL` and `VW_DYN_*`, preserves `CmPri` permission resources where stable keys match, and uses the same HMAC, technical-user, JSON envelope, OpenAPI, and Docker release patterns already used by the current API module.

**Tech Stack:** Java 8, Maven 3, Tomcat 7, MariaDB, Hibernate dynamic-map entities through `ORMService` and `DataPO`, JUnit 4, Spring mock servlet tests, Docker Compose.

## Guardrails

- 本计划只实现 `viewClass=dyn` 的动态表视图配置 API。
- 不实现菜单、首页、按钮入口发布。
- 不创建或修改动态表结构；继续使用现有 `/api/v1/dynamic-tables`。
- 不管理动态表业务数据 CRUD。
- 不执行脚本沙箱，只做静态风险检查并返回 `warnings`。
- 删除视图只删除 `VW_URL`、`VW_DYN_*` 和当前视图独占 `CmPri`，不删除业务表、业务数据、日志表。
- 所有 Maven 命令使用 Java 8 和 `settings.local.xml`。
- 当前工作区已有未提交的 `platform/src/main/webapp/js/ws-ajax-ext.js` 与 `platform/src/main/webapp/js/ws-ajax.js` 修改，执行本计划时不得回滚或夹带提交。

package com.riversoft.api.modules.dynamic_table_views;

import com.riversoft.api.http.ApiRequest;
import java.util.Map;

public class DynamicTableViewController {
    private DynamicTableViewService service;

    public DynamicTableViewController() {
    }

    public DynamicTableViewController(DynamicTableViewService service) {
        this.service = service;
    }

    public Map<String, Object> list(ApiRequest request) {
        return service().list(request.getParameter("start"), request.getParameter("limit"));
    }

    public Map<String, Object> create(ApiRequest request) {
        return service().create(request.readJson(DynamicTableViewSnapshot.class), isDryRun(request));
    }

    public Map<String, Object> detail(String viewKey) {
        return service().export(viewKey);
    }

    public Map<String, Object> replace(String viewKey, ApiRequest request) {
        return service().replace(viewKey, request.readJson(DynamicTableViewSnapshot.class), isDryRun(request));
    }

    public Map<String, Object> patch(String viewKey, String section, ApiRequest request) {
        return service().patch(viewKey, DynamicTableViewSection.parse(section), request.readJson(Object.class), isDryRun(request));
    }

    public Map<String, Object> delete(String viewKey, ApiRequest request) {
        return service().delete(viewKey, request.getParameter("confirmViewKey"));
    }

    public Map<String, Object> validate(ApiRequest request) {
        return service().validate(request.readJson(DynamicTableViewSnapshot.class));
    }

    private boolean isDryRun(ApiRequest request) {
        return "true".equalsIgnoreCase(request.getParameter("dryRun"));
    }

    private DynamicTableViewService service() {
        if (service == null) {
            service = new DynamicTableViewService();
        }
        return service;
    }
}
```

package com.riversoft.api.modules.dynamic_table_views;

import org.apache.commons.lang3.StringUtils;

public enum DynamicTableViewSection {
    BASE("base"),
    FIELDS("fields"),
    QUERIES("queries"),
    LIMITS("limits"),
    PROCESSORS("processors"),
    VARIABLES("variables"),
    SUBVIEWS("subviews"),
    BUTTONS("buttons"),
    WEIXIN("weixin"),
    SCRIPTS("scripts");

    private final String value;

    DynamicTableViewSection(String value) {
        this.value = value;
    }

    public String value() {
        return value;
    }

    public static DynamicTableViewSection parse(String value) {
        for (DynamicTableViewSection section : values()) {
            if (section.value.equals(StringUtils.trimToEmpty(value))) {
                return section;
            }
        }
        throw DynamicTableViewErrors.invalidSnapshot("不支持的动态表视图区块：" + value);
    }
}
```
