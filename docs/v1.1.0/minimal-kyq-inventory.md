# v1.1.0 极简 kyq 初始盘点

本文记录 2026-04-26 对当前本地 `kyq` 库的非破坏性盘点结果，用于后续生成极简初始化库。

## 盘点环境

- 数据来源：当前工作区 `db/data`
- 容器：`mariadb:10.11`
- 数据库：`kyq`
- 操作方式：只读查询，不删除、不重建、不重新导入

## 优先清理前缀

以下表前缀包含业务样例、历史流程数据、集成账号或敏感字段，默认不进入极简库数据部分：

- `fin`
- `sell`
- `pur`
- `hr`
- `oa`
- `sto`
- `prj`
- `shop`
- `demo`
- `wx`

这些表的结构可以保留，数据默认清空。若首页或菜单强依赖某些演示数据，应单独列入白名单并脱敏。

## 需要重点脱敏的字段类型

盘点发现以下字段类型需要重点处理：

- 用户密码：`us_user.PASSWORD`
- 手机和电话：`MOBILE`、`PHONE`、`TEL_PHONE`、`*_PHONENUM`
- 邮箱：`MAIL`、`EMAIL`
- 微信标识：`WXID`、`WX_*`
- 第三方密钥：`TOKEN`、`SECRET`、`APP_SECRET`、`PAY_SECRET`、`ENCODING_AES_KEY`
- 业务联系人：`CUSTOMER_*`、`CLIENT_*`、`SUPPLIER_*`

## 下一步建议

1. 先导出只含结构的 `minimal-kyq.sql`。
2. 选择是否保留一个默认管理员账号；如果保留，使用明确的公开初始化密码并在 README 中标注仅供本地体验。
3. 按白名单补入 `us_*`、`cm_*`、必要 `dev_*`、必要 `tb_*` 的最小数据。
4. 默认清空业务前缀、运行时流程实例、日志、快照和第三方集成数据。
5. 从零导入后用 `/`、`/ueditor/` 和登录页访问结果反推缺失元数据。
